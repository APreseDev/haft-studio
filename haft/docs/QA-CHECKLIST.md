# چک‌لیست تست نهایی (دستی، روی سیستم خودتان)

هر مورد را بعد از انجام تیک بزنید و اگر چیزی خراب بود، متن خطا یا اسکرین‌شات بفرستید.

## ۱. بیلد (روی سیستم خودتان)

- [ ] `npm ci` بدون خطا تمام شود
- [ ] `npm run lint` بدون خطا تمام شود
- [ ] `npm run build` بدون خطا تمام شود و پوشه‌ی `dist` ساخته شود
- [ ] `npm run preview` را بزنید و آدرس نمایش‌داده‌شده را باز کنید (این نسخه‌ی نهایی است، نه `npm run dev`)

## ۲. نمایش (روی `preview`)

- [ ] دسکتاپ: عرض ۱۴۴۰ و ۱۰۲۴
- [ ] موبایل: عرض ۳۹۰ و ۳۲۰ (با ابزار توسعه‌دهنده‌ی مرورگر یا گوشی واقعی)
- [ ] Console مرورگر: هیچ خطای قرمز نباشد
- [ ] Network: هیچ فایل ۴۰۴ نباشد (عکس‌های تیم، فونت، آیکون)
- [ ] فونت وزیرمتن و جهت راست‌به‌چپ درست باشد، متن‌ها بیرون نزنند
- [ ] عکس‌های تیم داخل دایره درست و صورت‌ها دیده شود
- [ ] بخش نمونه‌کارها در `preview` فقط عبارت «نمونه‌کارها به‌زودی این‌جا اضافه می‌شود.» را نشان دهد (در `npm run dev` کارت‌های placeholder دیده می‌شود)

## ۳. انیمیشن و سه‌بعدی

- [ ] صحنه‌ی سه‌بعدی پس‌زمینه لود شود و روان باشد
- [ ] ظاهر شدن بخش‌ها هنگام اسکرول (GSAP) کار کند
- [ ] اسکرول نرم (Lenis) روی دسکتاپ کار کند و لینک‌های منو به بخش درست بروند و زیر منو نروند
- [ ] روی موبایل پس‌زمینه سبک‌تر است و صفحه نمی‌پرد
- [ ] با فعال‌بودن «Reduce motion» در سیستم‌عامل، سایت بدون انیمیشن ولی کامل دیده شود
- [ ] منوی موبایل باز و بسته شود (با Escape هم)

## ۴. فرم تماس (ایمیل واقعی)

- [ ] فرم خالی: پیام خطا و رفتن فوکوس روی «نام»
- [ ] شماره‌ی `abc`: پیام «شماره تماس معتبر نیست»
- [ ] ارسال واقعی با شماره‌ی فارسی: پیام موفقیت و رسیدن ایمیل (Inbox و Spam را چک کنید)
- [ ] دو بار کلیک سریع روی ارسال: فقط یک ایمیل برسد
- [ ] قطع اینترنت و ارسال: پیام قطع اینترنت و حفظ متن فرم
- [ ] لینک‌های تماس: تلفن، ایمیل و اینستاگرام درست باز شوند

## ۵. بعد از انتشار روی Cloudflare (`pages.dev` و سپس دامنه)

- [ ] آدرس اشتباه (مثل `/test`) صفحه‌ی ۴۰۴ فارسی نشان دهد
- [ ] `/robots.txt` باز شود
- [ ] در پاسخ سایت هدرهای `X-Content-Type-Options` و `X-Frame-Options` باشد (`curl -I آدرس`)
- [ ] خطای CSP در Console نباشد، بعد هدر را از Report-Only به حالت اجباری ببرید
- [ ] `https://www...` به آدرس اصلی ریدایرکت شود
- [ ] قفل HTTPS مرورگر سالم باشد
- [ ] سایت را از داخل ایران و با اینترنت‌های مختلف باز کنید
- [ ] Lighthouse (در Chrome) روی موبایل بگیرید و نتیجه را بفرستید

## ۶. زبان، حالت تیره/روشن و تغییرات اخیر (دستی، روی `preview`)

- [ ] دکمه‌ی `EN`/`FA` در منو: همه‌ی متن‌ها عوض شود، جهت صفحه راست‌به‌چپ/چپ‌به‌راست شود و بعد از رفرش همان زبان بماند
- [ ] در حالت انگلیسی هیچ متن فارسی دیده نشود (به‌جز شماره‌ی تلفن) و فلش دکمه‌ها به سمت جلو باشد
- [ ] دکمه‌ی خورشید/ماه: حالت روشن و تیره، پس‌زمینه‌ی سه‌بعدی هم‌رنگ شود، بعد از رفرش بدون چشمک بماند
- [ ] حالت روشن: متن‌ها خوانا باشند و نوار سرمه‌ای شعار خوانا بماند
- [ ] با اسکرول از هیرو، عدد ۷ پس‌زمینه نرم محو شود و با اسکرول به بالا برگردد
- [ ] نوار کرمی زیر هیرو روی عرض ۱۳۶۶، ۱۹۲۰ و ۲۵۶۰ هیچ جای خالی نداشته باشد و در انگلیسی خلاف جهت فارسی حرکت کند
- [ ] بخش «روش کار»: هر قدم هم‌عرض صفحه باشد، با اسکرول وارد و خارج شود و با اسکرول به بالا برعکس شود
- [ ] لوگو در منو، فوتر و تب مرورگر (و صفحه‌ی ۴۰۴) درست و بدون کشیدگی دیده شود، در هر دو حالت
- [ ] فرم تماس به زبان انگلیسی: پیام‌های خطا و موفقیت انگلیسی باشند و ایمیل دریافتی خدمت را به فارسی نشان دهد
- [ ] Console: خطای CSP برای اسکریپت اولیه‌ی `index.html` نباشد (هش در `_headers`)
